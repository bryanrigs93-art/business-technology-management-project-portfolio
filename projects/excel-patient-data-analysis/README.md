# Excel Patient Data Analysis

Esta carpeta contiene mi proyecto de Excel sobre limpieza y análisis descriptivo de datos de pacientes.

Lo dejé separado dentro del repositorio para que sea fácil encontrar los archivos originales del trabajo. El README principal explica el contexto completo del proyecto, qué hice, qué aprendí y cómo lo explicaría en una entrevista.

## Por qué este proyecto es importante para mi portafolio

Este proyecto muestra una base realista de análisis de datos en Excel: revisar datos, encontrar problemas, documentar correcciones, crear resúmenes y explicar resultados. No es un proyecto avanzado de BI todavía, pero sí representa un paso importante hacia Data Analytics y Business Intelligence.
